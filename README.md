# IELTS 學習助手

雅思學習工具，同一套單字學習系統有兩個版本：

| 版本 | 位置 | 用途 |
|---|---|---|
| **網頁版 PWA** | 根目錄（`index.html`） | 手機／平板／筆電，可加到主畫面離線用，通勤時單手操作 |
| **指令列版 CLI** | [`cli/`](./cli) | 桌機用，Python + SQLite |

兩邊共用同一套設計：同樣的 SM-2 參數、同樣的三軌排程、同樣的 CSV 格式、同樣的 30 個種子單字
（網頁版的種子資料由 `cli/ielts/data/seed_cards.csv` 產生）。CSV 可以在兩邊互相搬。

---

## 核心設計原則

**不做「單字 → 中文對照」的卡片。** 每張卡的記憶點固定是四個維度：

| 維度 | 為什麼是它 |
|---|---|
| 例句 | 記語境，不記孤立的字 |
| 搭配詞 | 雅思寫作口說的自然度靠搭配 |
| 字根字首 | 理解型記憶的抓手，記得住也猜得到生字 |
| 同義詞群 | 雅思聽力閱讀的核心機制是同義替換 |

中文提示只在拼字練習與補完模式出現；通勤複習的卡片正反面都不給中文對照。

## 網頁版：五種學習模式

打開 `index.html`（或加到手機主畫面）就能用，資料存在瀏覽器本機，不需要帳號也不上傳任何東西。

| 模式 | 做什麼 |
|---|---|
| 🚇 **通勤複習** | 看單字 → 翻出四維度 → 評分 Again/Hard/Good/Easy。手機單手可按，筆電可用空白鍵翻面、1-4 評分 |
| ✍️ **拼字練習** | 例句挖空 + 中文提示 → 打出完整拼字 → 逐字元比對並標出錯在哪裡。目標字在例句、搭配詞、字根說明裡都會一併遮掉，不會洩題 |
| 🔁 **同義詞測驗** | 給一個字，列出 2 個以上同義詞。比對容忍大小寫與詞形變化（`Reducing` 對得上 `reduce`） |
| 🗣️ **主動輸出** | 給一個 active 字 + 一個雅思常見題幹，要你造句；句子存起來，可整份匯出成 markdown 貼給 AI 批改 |
| 🧩 **補完卡片** | 逐一補齊缺的例句／搭配／字根／同義詞，只問缺的欄位 |

另外還有：升級 active（每週把認讀已經穩的字升級成主動詞彙）、卡片清單、手動新增卡片、CSV 匯入匯出。
統計在「進度」分頁：每日學習計畫（會直接告訴你今天該做哪一項）、今日各軌待複習數、連續學習天數、passive/active 比例、拼字錯誤率與最常拼錯的字、各分類與主題的覆蓋進度。

這個 App 只做單字，不連任何外部服務。原本的閱讀、聽力與 AI 解析都已移除；
保留下來的是每日提醒與連續學習紀錄。造句要批改就用「匯出成 markdown」自己貼給 AI。

### 第一次打開會發生什麼

- 灌入 30 個四維度齊全的種子單字
- 把舊版的 100 個單字轉成卡片（保留例句與搭配詞；缺字根與同義詞 → 標記為「不完整」，交給補完模式）
- 舊版已經標記為「認識／複習中」的字，會換算成認讀軌的排程起點，進度不會歸零

## 間隔重複（SM-2）

| 評分 | 新間隔 | ease 調整 |
|---|---|---|
| Again | 重置為 1 天 | −0.20，記一次 lapse |
| Hard | ×1.2 | −0.15 |
| Good | ×ease（首答 1 天 → 次答 6 天） | 不變 |
| Easy | ×ease×1.3 | +0.15 |

ease 下限 1.3、上限 3.0；間隔上限兩年；4 天以上的間隔加 ±5% 隨機抖動，避免大量卡片擠在同一天到期。

**排程分成三軌**（認讀 / 拼字 / 同義詞）：「認得這個字」「拼得出這個字」「講得出同義詞」是三種不同能力，
各自獨立排程。拼錯一次只會把拼字進度壓回明天，不會連帶把已經很熟的認讀間隔打回原點。

## CSV 格式（兩個版本通用）

只有 `word` 必填。欄位名大小寫、底線、常見別名（`example`／`root`／`中文`／`詞性`…）都對得上；
逗號或 Tab 分隔皆可，引號內的逗號不會被切開。缺欄位的列會照樣匯入並標記為不完整。

| 欄位 | 說明 |
|---|---|
| `word` | 單字或片語 |
| `pos` | 詞性 |
| `example_sentence` | 英文例句 |
| `collocations` | 搭配詞，用 `;` 分隔 |
| `root_analysis` | 字根字首拆解 |
| `synonyms` | 同義詞，用 `;` 分隔 |
| `category` | AWL / 高頻話題字 / Task1圖表用語 / 口說表達 |
| `topic` | 環境、教育、科技、健康、都市化、犯罪、媒體… |
| `card_type` | `passive`（預設）或 `active` |
| `zh_hint` | 中文提示（只在拼字與補完模式顯示） |
| `notes` | 自己的筆記 |

## 檔案結構

```
index.html              網頁版外殼（版面 + 樣式）
css/vocab.css           單字模組樣式
js/srs.js               SM-2 排程（純函式）
js/textutil.js          挖空、拼字比對、同義詞寬鬆比對
js/cards.js             30 個種子單字（由 cli 的 CSV 產生）
js/legacy-words.js      舊版 100 個單字（首次啟動時匯入）
js/store.js             單字庫：卡片、三軌排程、各種紀錄（localStorage）
js/vocab.js             五種模式的介面
js/dashboard.js         進度頁的單字統計
js/app.js               設定／每日推送／連續學習／學習計畫
sw.js                   Service Worker（離線快取）
tests/                  網頁版測試（見 tests/README.md）
cli/                    指令列版本（見 cli/README.md）
```

要加新模式：在 `js/vocab.js` 加一組 `startXxx / renderXxx`，再到首頁的 `modeCard` 清單掛一個入口。
介面層只呼叫 `Store` 與 `TextUtil`，不自己碰 localStorage。

```bash
node tests/engine.test.js                      # 55 項：排程、文字處理、資料層、CSV、舊資料轉換
python3 -m http.server 8899 --bind 127.0.0.1 & # 瀏覽器端到端需要先起一個 server

```

## 指令列版本

```bash
cd cli
python3 -m ielts init      # 建立資料庫並灌入 30 個範例字
python3 -m ielts stats     # 看今天要做什麼
python3 -m ielts review    # 通勤複習
```

完整說明見 [`cli/README.md`](./cli/README.md)。
